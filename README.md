# 🍛 Tadka Tales - Indian Restaurant

A beginner-friendly **Indian restaurant menu website** created using **HTML**.

## 🌶️ About the Project

Tadka Tales is a simple restaurant menu website that showcases a variety of Indian dishes, including starters, main courses, Indian breads, biryani, desserts, drinks, and special combos.

This project was created as part of my **HTML learning and practice**.

## 🍽️ Menu Includes

* 🥗 Starters
* 🍲 Main Course
* 🫓 Indian Breads
* 🍚 Rice & Combos
* 👨‍🍳 Chef's Special
* 🍰 Desserts
* 📍 Restaurant Information

## 🛠️ Technologies Used

* HTML5

## 🎯 What I Practiced

Through this project, I practiced:

* HTML headings and paragraphs
* Links and navigation
* Tables
* Lists
* Sections
* Basic HTML formatting
* Semantic HTML elements
* Anchor links using `id`
